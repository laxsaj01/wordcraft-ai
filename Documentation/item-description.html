WordCraft AI - AI Content Writer & SEO Article Generator SaaS (Node.js Script)

WordCraft AI is a complete, self-hosted AI writing platform that you can launch as your own SaaS business. Your customers log in and generate SEO blog articles, product descriptions, ad copy, marketing emails and social posts with AI - streamed live, word by word, just like ChatGPT. You charge them for credits and subscriptions through PayPal or Stripe, and you keep the revenue. Everything is included in one purchase: the writing studio, AI chat assistant, billing, referral program, developer API, blog, support tickets, a full admin panel, 5 languages with RTL support, and dark mode.

Start an AI writing business, not just a website

Most AI tools lock you into someone else's platform. WordCraft AI runs on your own server, under your own domain and brand, with your own pricing. It removes the problems that usually stop an AI SaaS launch:

  • No vendor lock-in - works with OpenAI, DeepSeek, Groq, OpenRouter, Together, or a self-hosted model (Ollama, vLLM). Paste a base URL, an API key and a model name, and you are ready. Switching providers takes seconds, so your business never depends on one company.
  • No database server to install - data is stored in a single SQLite file that is created automatically. Installation is npm install then npm start, followed by a one-screen setup wizard.
  • Fair credit system - customers see the exact credit cost before they generate anything. If the AI provider fails, credits are automatically refunded and logged. No support tickets about lost credits.
  • Real-time streaming - content appears word by word with a stop button, the experience users already know from ChatGPT-style tools. No blank screens and no waiting.
  • Built-in ways to earn - subscription plans and credit top-ups with PayPal and Stripe checkout, a referral program that grows your user base, and a paid developer API as a second revenue stream.
  • Reach everyone - English, Spanish, French, German and Arabic, with full right-to-left layout. Dark and light themes. Fully responsive on phones, tablets and desktops.

Developer API included

Customers on an API-enabled plan can generate content from their own applications using secure personal API keys (wc_ keys): list templates, check remaining credits, and generate content with a single request.

  • GET /api/v1/templates
  • GET /api/v1/credits
  • POST /api/v1/generate
